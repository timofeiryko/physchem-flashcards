## 📚 Структура курса

1. **Часть I. Химическая термодинамика** (Вопросы 1–44, 8 тем)
   - Начала термодинамики, потенциалы, соотношения Максвелла, химический потенциал
   - Уравнение Гиббса-Дюгема, фугитивность, летучесть реальных газов
   - Термодинамика растворов: идеальные, бесконечно разбавленные, реальные, активности
   - Химическое равновесие, изотерма/изобара/изохора реакции, закон действующих масс
   - Фазовые равновесия: правило фаз Гиббса, уравнение Клапейрона-Клаузиуса, коллигативные свойства
   - Осмос, мембранное равновесие Доннана

2. **Часть II. Электрохимия** (Вопросы 45–107, 7 тем)
   - Электролиты, ионная сила, предельный закон Дебая-Хюккеля
   - Электропроводность растворов, подвижность ионов, закон Кольрауша
   - Электрохимические цепи, потенциалы полуэлементов, уравнение Нернста
   - Двойной электрический слой (ДЭС): модели Гельмгольца, Гуи-Чепмена, Штерна-Грэма
   - Электрокапиллярные явления, уравнение Липпмана
   - Кинетика электродных процессов: уравнение Батлера-Фольмера, уравнение Тафеля
   - Диффузионная кинетика, стационарная диффузия, вращающийся дисковый электрод (уравнение Левича)

3. **Часть III. Поверхностные явления и коллоидная химия** (Вопросы 108–147, 5 тем)
   - Поверхностное натяжение, термодинамика искривленных поверхностей (Лаплас, Кельвин)
   - Адсорбция: фундаментальное уравнение Гиббса, изотермы Ленгмюра, Фрейндлиха, БЭТ
   - Смачивание и растекание, краевой угол (уравнение Юнга, Юнга-Дюпре)
   - Растворы ПАВ: мицеллообразование, ККМ, солюбилизация, точки Краффта и помутнения
   - Устойчивость и коагуляция коллоидных систем: теория ДЛФО, расклинивающее давление, правило Шульце-Гарди
   - Электрокинетические явления: электрофорез, электроосмос, потенциал течения, седиментации, формула Гельмгольца-Смолуховского

4. **Часть IV. Химическая кинетика** (Вопросы 148–190, 7 тем)
   - Формальная кинетика: скорость реакции, порядки, период полупревращения
   - Интегрирование кинетических уравнений для 0, 1, 2, 3 порядков
   - Температурная зависимость скорости: уравнение Аррениуса
   - Сложные реакции: параллельные, последовательные, обратимые; метод квазистационарных концентраций (Боденштейн), метод квазиравновесия
   - Теории элементарного акта: теория активных соударений (ТАС), теория переходного состояния (ТПС, уравнение Эйринга)
   - Цепные реакции: неразветвленные и разветвленные цепи (Семенов, полуостров воспламенения)
   - Фотохимия (Штарк-Эйнштейн, квантовый выход) и ферментативный катализ (кинетика Михаэлиса-Ментен, Бриггс-Холдейн)
